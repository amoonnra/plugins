# Support

## Before Reporting an Issue

1. Confirm that the file language mode is JSON or JSON with Comments.
2. Confirm that `jsonBooleanToggle.enabled` is `true`.
3. Confirm that `editor.inlayHints.enabled` is set to `on` or `onUnlessPressed`.
4. Reload the Visual Studio Code window.

When reporting a problem, include the Visual Studio Code version, operating system, a minimal JSON example, and the steps needed to reproduce the behavior. Do not include secrets or private configuration values.
