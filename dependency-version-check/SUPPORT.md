# Support

Report issues at [amoonnra/plugins](https://github.com/amoonnra/plugins/issues) with **Dependency Version Check** in the title.

Include VS Code and extension versions, OS / remote environment, package manager, a minimal anonymous manifest, relevant installed versions and whether you use a multi-root workspace or monorepo. Do not include credentials, private registry tokens or unredacted configuration files.

Try **Dependency Version Check: Refresh All Projects** and inspect **View: Toggle Output → Dependency Version Check**. Package installation output is in the task terminal. Check `dependencyVersionCheck.exclude`, optional / peer settings and the detected installation directory when troubleshooting.
