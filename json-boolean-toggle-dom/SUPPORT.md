# Support

## Before Reporting an Issue

1. Confirm that the file language mode is JSON or JSON with Comments.
2. Confirm that `jsonBooleanToggleDom.enabled` is `true`.
3. Confirm that `editor.inlayHints.enabled` is set to `on` or `onUnlessPressed`.
4. Run `JSON Boolean Toggle DOM: Install Experimental UI` again after every Visual Studio Code update.
5. Reload every Visual Studio Code window.

When reporting a problem, include the Visual Studio Code version, operating system, installation method, patch command result, and a minimal JSON example. Do not include secrets or private configuration values.
