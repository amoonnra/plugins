# Support

Before reporting a problem, confirm:

1. The file is named `package.json` and uses JSON or JSON with Comments language mode.
2. `editor.links` is enabled.
3. The package is installed in a local or parent `node_modules` directory.
4. You are using Ctrl+click / Cmd+click, or Alt+click when the multi-cursor modifier is Ctrl/Cmd.
5. You have opened the monorepo root if you expect a hoisted package folder to appear in the Explorer.

Report issues in the [GitHub issue tracker](https://github.com/amoonnra/plugins/issues). Include the VS Code version, operating system, package manager, a minimal manifest, relevant folder layout, and steps to reproduce. Indicate whether the workspace is local, WSL, SSH, or a Dev Container.

Do not include tokens, credentials, private registry configuration, or other secrets.
